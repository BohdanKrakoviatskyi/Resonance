# REPORT-4 — Полная замена плашки источника и кнопок сдвига текста на круглую кнопку в шапке с поповером-ползунком (`−10..+10 с`, шаг `0.25 с`)

Ветка: `overnight/lyrics`

---

## 1. Почему раньше плашка и кнопки `−0.5 с / 0.0 с / +0.5 с` оставались на экране

### Проверил (файл:строка / тест)
- В `src/components/Lyrics.tsx` (до коммита `9b20c2d`, строки `592–719`) рендерился компонент `LyricsDebugInfoBar` с `position: absolute; left: 2.5; right: 12; top: 2.5; z-index: 10`, который лежал поверх верхних строк текста песни в обоих режимах (`variant="panel"` и `variant="imm"`).
- В `src/state/ui.ts` (до коммита `9b20c2d`, строка `87`) дефолтное значение `showLyricsDebugInfo` было `true`, а условие `if (!show && syncType !== 'Synced') return null;` в `LyricsDebugInfoBar` (строка `622`) гарантировало, что для любого `Synced`-трека ряд из 3 кнопок (`−0.5 с`, `0.0 с`, `+0.5 с`) рендерился всегда, даже при выключенной настройке.
- В `git log` на ветке `overnight/lyrics` последним коммитом перед началом сессии был `e6aae57` (`REPORT-2`), то есть удаление `LyricsDebugInfoBar` и замена на круглую кнопку с поповером ранее не были закоммичены в рабочее дерево.

### Предполагаю
- Предыдущая сессия не сохранила изменения на диск или работала в другом рабочем дереве, поэтому в `src/components/Lyrics.tsx` оставалась старая реализация из `REPORT-2`.

## 2. Где теперь находятся кнопка сдвига и поповер, как они устроены

### Проверил (файл:строка / тест)
- **Шапка блока текста (`src/components/Lyrics.tsx:788–803`):**
  - В `Lyrics` выделена отдельная flex-шапка `.lyrics-header` (`shrink-0 items-center justify-end gap-1.5`), которая располагается **над** контейнером со строками текста (`min-h-0 flex-1`). Когда поповер закрыт, поверх строк текста песни вообще нет никаких плашек, баннеров, таймеров автопоказа или кнопок.
  - В шапке рендерятся ровно две кнопки рядом: **слева** круглая кнопка сдвига `LyricsOffsetPopover`, **справа** кнопка поиска/смены текста `ManualLyricsPicker` (`src/components/Lyrics.tsx:795–802`).
  - Это работает идентично в правой боковой панели (`variant="panel"`, размер круглой кнопки `h-8 w-8`) и в полноэкранном режиме (`variant="imm"`, размер `h-10 w-10`).
- **Круглая кнопка сдвига (`src/components/Lyrics.tsx:664–700`):**
  - Иконка: `history` (часы со стрелкой синхронизации).
  - Подсказка при наведении для `Synced`-текста: `t('lyricsOffsetBtn')` → **«Сдвиг текста»**.
  - Индикатор сохранённого сдвига: если у текущего `track.id` в `ui.lyricsOffsets[track.id]` сохранён ненулевой сдвиг, на кнопке отображается аккуратная круглая точка (`bg-primary`) в правом верхнем углу (`src/components/Lyrics.tsx:693–698`).
  - Состояние для `Plain`-текста (без таймкодов) или отсутствующего текста: кнопка `disabled={!isSynced}`, отображается приглушённо-серой (`cursor-not-allowed bg-sc-high/35 text-on-surface-variant/35`) с подсказкой `t('lyricsOffsetNoSync')` → **«У этого текста нет таймкодов»**. Поповер при клике не открывается.
- **Поповер (`src/components/Lyrics.tsx:702–779`):**
  - Открывается только по клику на круглую кнопку и закрывается по клику вне поповера (`pointerdown` capture) или по клавише `Escape` (`src/components/Lyrics.tsx:617–634`).
  - **1-й блок (сверху):** компактная строка источника, типа синхронизации, совпавшего трека и дельты длительности (`LRCLIB · SYNCED · Артист — Название · разница по длительности ±X.X с`) + жёлтый бейдж **«Возможен сдвиг»** при `possibleOffsetWarning` (дельта `4–10 с`).
  - **2-й блок (посередине):** ползунок `<input type="range" min={-10} max={10} step={0.25} />` от `−10` до `+10 с` с центром `0`, отображением текущего сдвига справа (`+0.75 с`, `−0.25 с`, `0.00 с`) и подписями **«← Раньше (−)»** слева и **«(+) Позже →»** справа (`src/components/Lyrics.tsx:724–749`).
  - **3-й блок (снизу):** две кнопки — **«Сбросить»** (выставляет live-сдвиг в `0`) и **«Сохранить»** (записывает сдвиг в `lyricsOffsets[track.id]`, показывает состояние **«Сохранено»** с галочкой; если сохраняется `0`, запись для `track.id` удаляется из словаря и точка на круглой кнопке пропадает).
- **Живой (live) сдвиг и синхронизация с `Alt+[` / `Alt+]`:**
  - В `src/state/ui.ts:93, 152–188` добавлено несохраняемое в `localStorage` поле `lyricsLiveDraft: { trackId, offsetSec } | null`.
  - При перетаскивании ползунка или нажатии `Alt+[` (`−0.25 с`) / `Alt+]` (`+0.25 с`) (`src/state/shortcut-runtime.ts:51–59`) меняется `lyricsLiveDraft`, от которого напрямую зависит `SyncedLyrics` (`src/components/Lyrics.tsx:96, 118–124`). Активная строка текста сдвигается мгновенно (и во время воспроизведения, и на паузе, для SoundCloud и YouTube Music).
  - При переключении трека (`useEffect` по `track.id` в `src/components/Lyrics.tsx:607–611`) несохранённый черновик сбрасывается (`clearLiveTrackLyricsOffset()`), и для нового трека берётся его собственный сохранённый сдвиг (или `0`).
  - В `src/state/shortcuts.ts:35–36, 91–94` дефолтные биндинги сдвига обновлены на `Alt+[` и `Alt+]` с автоматической миграцией старых дефолтов `[` / `]`, чтобы одиночная клавиша `]` никогда не конфликтовала с `Mute`.
- **Чистка старого кода и настроек:**
  - Из `src/pages/Settings.tsx` удалён неиспользуемый переключатель `Lyrics source info bar` (`showLyricsDebugInfo`), при этом сам ключ `showLyricsDebugInfo` в `src/state/ui.ts` сохранён для обратной совместимости хранилища.
  - `grep` по `src/` подтвердил полное отсутствие `LyricsDebugInfoBar`, `LyricsSourceIndicator`, `−0.5 с`, `+0.5 с`, `0.0 с` и `4500`.

### Предполагаю
- Визуальное выравнивание поповера (`right-0 top-[calc(100%+8px)]` шириной `320px` в панели и `340px` в `imm`) помещается в ширину правой колонки без горизонтального скролла (требует визуальной проверки владельцем в живом окне).

## 3. Проверка направления знака сдвига («Раньше» vs «Позже»)

### Проверил (файл:строка / тест)
- В `src/lib/lyrics-match.ts:404–409` (`findSyncedLyricLineIndex`) эффективное время поиска активной строки вычисляется по формуле:
  ```ts
  const effectiveTime = realTimeSec - clampLyricsOffset(offsetSec) + leadInSec;
  ```
- **Отрицательный сдвиг (`offsetSec < 0`, ползунок влево — «Раньше»):**
  - Вычитание отрицательного числа увеличивает `effectiveTime` (`realTimeSec + |offsetSec| + 0.12`).
  - Строка с таймкодом `12.00 с` становится активной уже на `11.70 с` плеерного времени — то есть текст песни появляется **РАНЬШЕ**.
  - При клике по строке (`getSeekTimeForLyricLine`, `src/lib/lyrics-match.ts:422–424`) плеер перематывает на `l.t + offsetSec` (на более раннюю секунду аудио, где эта строка теперь звучит).
- **Положительный сдвиг (`offsetSec > 0`, ползунок вправо — «Позже»):**
  - Вычитание положительного числа уменьшает `effectiveTime` (`realTimeSec - offsetSec + 0.12`).
  - Строка с таймкодом `12.00 с` активируется только когда плеер дойдёт до `12.00 + offsetSec` — то есть текст песни появляется **ПОЗЖЕ**.
  - При клике по строке плеер перематывает на `l.t + offsetSec` (на более позднюю секунду аудио).
- Это поведение зафиксировано и проверено unit-тестом `shifts active synced lyric line earlier for negative offset and later for positive offset in 0.25s steps` в `src/lib/lyrics-match.test.mjs:350–376`.

### Предполагаю
- Дополнительных расхождений между подписями ползунка и математикой синхронизации нет.

## 5. Короткий чеклист для ручной проверки утром (4 пункта)

1. **Чистое поле текста и кнопка в шапке:** открой любой трек с синхронизированным текстом (в правой панели и в полноэкранном режиме `F`) — убедись, что поверх строк текста нет никаких плашек и кнопок `−0.5 / 0.0 / +0.5`, а в шапке слева от кнопки поиска («Другой текст») появилась круглая кнопка с иконкой часов («Сдвиг текста»).
2. **Поповер и живой ползунок:** нажми на круглую кнопку сдвига — проверь строку источника сверху, подвигай ползунок влево («Раньше») и вправо («Позже») или нажми `Alt+[` / `Alt+]` (шаг `0.25 с`) — активная строка должна переключаться сразу вживую.
3. **Сохранение, точка-индикатор и сброс при смене трека:** сдвинь ползунок и переключи трек *без* нажатия «Сохранить» (сдвиг не должен сохраниться); затем выставь сдвиг, нажми **«Сохранить»** (появится точка на круглой кнопке, сдвиг сохранится за этим треком), а после нажми **«Сбросить» → «Сохранить»** (сдвиг вернётся в `0.00 с`, точка исчезнет).
4. **Тексты без таймкодов (Plain):** открой трек, у которого найден только обычный текст без таймкодов (`Plain`) — круглая кнопка сдвига должна быть неактивной (серой) с подсказкой «У этого текста нет таймкодов».
